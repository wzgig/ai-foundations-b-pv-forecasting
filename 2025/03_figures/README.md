# 03 图表素材

本目录保存跨链路复用的图像素材。正式链路运行生成的图优先留在 `../02_problem_solutions/**/outputs/figures/`；只有报告、静态页或论文多处复用的图片才放到这里。

| 子目录 | 说明 |
| --- | --- |
| `paper_assets/` | 报告和论文素材图，包括数据驱动预测流程图、历史流程图、页眉标识等。 |
| `exploratory_analysis/` | 探索性分析图。 |
| `scenario_comparisons/` | 运行场景或预测效果对比图。 |

文件命名建议：

- 新增图片优先使用“用途_对象_版本”的中文或英文短名。
- 不再使用 `图片3.png` 这类无法看出含义的名称。
- 若图片来自样张或课程模板，应在文件名或说明中保留来源。
