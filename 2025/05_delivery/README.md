# 课程交付工作台

本目录用于把已有光伏日前预测仓库整理成《人工智能基础B》期末大作业可提交材料。这里的文档不替代代码和模型结果，而是把课程通知、工程完成度、主报告、测试记录、视频脚本和最终打包动作串起来，方便最后提交前逐项核对。

## 文件索引

| 文件 | 用途 |
| --- | --- |
| `作业要求提取.md` | 从课程通知、A 题题面和附件指标中提取硬性要求。 |
| `交付完成度复盘.md` | 对照要求检查当前仓库完成情况、风险和收尾动作。 |
| `项目主报告_课程版.md` | 面向课程评分表的项目主报告草稿，可继续导出为 Word/PDF。 |
| `项目主报告_终稿.md` | 已补充分工、图表和测试分析的最终 Markdown 源稿。 |
| `项目主报告_终稿.docx` | 按长沙理工大学本科毕业设计（论文）撰写规范样张重排后的 Word 终稿。 |
| `项目主报告_终稿.pdf` | 按样张导出的 PDF 终稿，优先提交。 |
| `团队分工与项目计划.md` | 3/4 人团队职责模板、时间安排和最终确认事项。 |
| `功能性能稳定性测试表.md` | 功能测试、性能指标、稳定性和复现命令记录。 |
| `演示视频脚本.md` | 3 分钟以内 MP4 演示的分镜、台词和录屏路线。 |
| `网站使用指南与案例.md` | Streamlit 工作台和 GitHub Pages 的使用说明与案例。 |
| `最终提交包清单.md` | 最终压缩包命名、内容、体积控制和上传前检查。 |

## 当前判断

代码和模型主线已经具备可提交基础：站点机理诊断、历史功率基线、气象预报融合、运行场景归因和局地校正融合均有脚本、指标、图表和运行摘要。后续最容易丢分的环节是课程化主报告、真实 MP4 演示视频、团队信息、最终压缩包和平台上传确认。

本目录已补齐可编辑草稿、按样张排版的正式 Word/PDF 终稿和检查表。若后续继续改主报告正文，可运行 `2025/tools/export_csust_report.ps1` 重新生成 DOCX/PDF 并渲染检查。最终提交前仍需要人工确认团队成员姓名学号、录制 MP4，并在头歌或学习通平台完成上传。
