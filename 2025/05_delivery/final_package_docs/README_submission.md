```text

```

## 材料结构

| 目录 | 内容 | 对应要求 |
| --- | --- | --- |
| `01_项目主报告` | 项目主报告 PDF 与 Word 版本 | 不少于 2500 字，图文并茂，优先 PDF |
| `02_演示视频` | 3 分钟提交版 MP4 | 环境搭建、一键运行、功能演示、结果分析 |
| `03_项目代码包` | 可运行项目代码、依赖、启动脚本、模型与输出 | 可一键复现，含 `requirements.txt` 和 `run.bat` |
| `04_补充材料` | 评分辅助说明、核心图表、指标表、权重、运行证据、数据引用 | 补充创新点、效果截图、模型权重和数据说明 |

## 推荐检查顺序

1. 打开 `01_项目主报告/人工智能基础B_王子成组.pdf`，确认封面、图表、团队信息无误。
2. 播放 `02_演示视频/人工智能基础B项目视频.mp4`，该版本为 00:02:58、1080P。
3. 进入 `03_项目代码包`，按 `README.md` 或 `2025/RUN_GUIDE.md` 运行。
4. 查看 `04_补充材料/README_补充材料导读.md`，快速定位高分证据。
