# 数据集与引用说明

项目使用光伏电站历史功率、NWP 气象预报和 LMD 局地气象数据。提交包中保留了课程题面、附件指标口径和代码运行所需的样例/处理后数据，完整数据说明可在主报告和代码包 README 中查看。

## 评价口径

预测以 15 分钟分辨率输出目标日 96 点曲线。测试集选择第 2、5、8、11 月最后一周，误差统计仅限白昼时段。核心指标包括归一化均方根误差 `E_rmse`、归一化平均绝对误差 `E_mae`、归一化平均误差 `E_me`、相关系数 `r`、准确率 `C_R` 和合格率 `Q_R`。
