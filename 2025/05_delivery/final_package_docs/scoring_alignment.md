# 优秀档评分对齐说明

| 评分关注点 | 项目证据 | 文件位置 |
| --- | --- | --- |
| Python 工程化实现 | 统一任务入口、Streamlit 工作台、桌面启动器、运行健康检查 | `03_项目代码包/2025/run_project.py`、`app.py`、`start_software.vbs`、`tools/project_health_check.py` |
| 深度学习模型应用 | PureLSTM、FusionModel、BiFusionModel 与 Q4 输入消融 | `03_项目代码包/2025/02_problem_solutions/` |
| 大模型模块 | 指标解读、运行问答、离线兜底和可选 API 配置 | `03_项目代码包/2025/llm/` |
| 一键运行 | Windows 批处理与 VBS 启动入口 | `03_项目代码包/2025/run.bat`、`start_software.vbs` |
| 工程闭环 | 数据准备、训练/推理、指标计算、图表输出、报告视频、补充材料 | 本提交包四个主目录 |
| 测试与稳定性 | 语法检查、健康检查、25 个单元测试、结果汇总读取 | `04_补充材料/05_运行证据/运行验证记录.md` |
| 材料完整性 | 主报告、视频、代码包、补充材料、在线展示页 | `01_项目主报告`、`02_演示视频`、`03_项目代码包`、`04_补充材料` |

项目主题不是单纯的算法实验，而是面向光伏电站日前功率预测的运行工作台：通过历史功率、NWP 与 LMD 局地校正信息，支撑调度侧在日前计划中评估功率曲线、模型误差和异常场景。
