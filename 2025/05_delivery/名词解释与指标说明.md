# 名词解释与指标说明

本文档用于解释光伏电站日前功率预测与运行工作台中常见的模型、气象数据和评价指标。它面向项目答辩、录屏演示和后续复现检查，不替代代码说明，而是帮助读者把页面指标、训练脚本和工程场景对应起来。

## 1. 预测任务口径

本项目做的是光伏电站日前功率预测。一天被划分为 96 个 15 分钟点，模型在目标日前获得可用输入，预测目标日 00:00 至 23:45 的功率曲线。项目中多处出现的“白昼指标”只统计有发电意义的白昼样本，避免夜间功率接近 0 时把误差评价稀释。

关键时间概念如下。

| 名词 | 项目中的含义 | 工程意义 |
| --- | --- | --- |
| 起报时间 | 预测任务发起或可获得输入的时间，本项目表格中通常为目标日前一日 00:00。 | 对应调度侧提前编制日前计划的时间窗口。 |
| 预报时间 | 模型给出功率预测值的目标时刻。 | 一天 96 点预测表中的每一行。 |
| 目标日 | 被预测的自然日。 | 用于发电计划、运行复盘和误差统计。 |
| 白昼时段 | 代码中根据实际功率是否超过阈值判断的有效发电时段。 | 评价真正影响发电计划的时间段。 |
| 装机容量 | 本项目指标默认按 6600 kW，即 6.6 MW 归一化。 | 用于把不同量纲的功率误差转成可比较的考核指标。 |

## 2. 三个训练模型

项目比较 `PureLSTM`、`FusionModel` 和 `BiFusionModel`。它们不是三个孤立名字，而是三种复杂度不同的日前预测结构，用来观察模型表达能力增加后，预测精度和稳定性如何变化。

### 2.1 PureLSTM

`PureLSTM` 是纯 LSTM 时间序列基线模型。LSTM 的全称是 Long Short-Term Memory，属于循环神经网络的一种，适合处理有先后顺序的序列数据。

在项目中，`PureLSTM` 的作用是回答一个基础问题：只靠时间序列记忆，模型能把光伏功率日内形态学到什么程度。历史功率基线中，它主要读取前一日功率曲线；气象融合链路中，它读取“前一日功率 + 目标日气象特征”的序列输入，然后输出目标日 96 点功率。

它的优点是结构清晰、可作为保底基线，缺点是对云量突变、辐照快速波动这类局地天气扰动的表达能力有限。

### 2.2 FusionModel

`FusionModel` 是项目中的主力融合模型。问题 2 的代码里，它由 LSTM 分支、TCN 分支和 MLP 分支组成，并通过注意力权重把三个分支的输出合成最终预测。问题 3 和问题 4 中，它继续用于融合前一日功率、NWP 或 LMD 等多源输入。

可以把它理解为三类信息处理方式的组合：

| 分支 | 关注点 | 在光伏预测中的价值 |
| --- | --- | --- |
| LSTM 分支 | 序列前后依赖。 | 捕捉日内功率爬坡、午间平台和傍晚下降等连续形态。 |
| TCN 分支 | 局部时间窗口和多尺度卷积特征。 | 捕捉短时间波动、局部天气扰动和曲线形状变化。 |
| MLP 分支 | 全局非线性映射。 | 对整天输入做整体拟合，补充序列模型未覆盖的组合关系。 |
| 注意力融合 | 自动分配分支权重。 | 不同日期、不同天气条件下，让模型动态选择更有用的特征表达。 |

从当前结果看，`FusionModel` 是最适合作为演示主线的模型：历史功率基线、NWP 气象融合和 mixed 局地校正三条链路里，它都给出了稳定且容易解释的结果。

### 2.3 BiFusionModel

`BiFusionModel` 是增强型融合模型。代码中采用 BiLSTM、TCN 和 Transformer 等结构组合，试图同时利用双向序列表达、卷积局部特征和注意力式全局依赖。

它的设计目标是提高模型表达能力，适合用来验证“更复杂的结构是否一定更好”。当前结果显示，`BiFusionModel` 并不总是最优。这一点很重要：工程项目不只追求模型名字更复杂，而是要看白昼误差、准确率、合格率和运行稳定性。当前项目最终更推荐 `FusionModel`，原因是它在精度、复杂度和复现成本之间更均衡。

## 3. 气象与输入数据

光伏功率受太阳高度、辐照度、云量、温度、风速和局地设备状态影响。项目不只使用历史功率，还引入 NWP 和 LMD，目的是让模型提前知道目标日的天气条件。

### 3.1 NWP

`NWP` 是 Numerical Weather Prediction，即数值天气预报。它来自气象预报模型，对未来天气变量进行网格化预测。

本项目中使用的 NWP 特征包括：

| 字段 | 含义 |
| --- | --- |
| `nwp_globalirrad` | 数值天气预报给出的全球水平辐照度或总辐照相关量。 |
| `nwp_directirrad` | 直接辐照相关量。 |
| `nwp_temperature` | 目标时刻气温。 |
| `nwp_humidity` | 相对湿度。 |
| `nwp_windspeed` | 风速。 |
| `nwp_pressure` | 气压。 |
| `nwp_winddirection` | 风向，代码中会转换为连续的 `wind_x`、`wind_y`。 |

NWP 的优势是可以在目标日前获得，因此符合日前预测要求；不足是空间分辨率通常较粗，可能不能完全描述电站附近的云团、地形和局地辐照变化。

### 3.2 LMD

`LMD` 在本项目中指 Local Meteorological Data，即局地气象数据。它更贴近光伏电站局部环境，用于补足粗尺度 NWP 的不足。

问题 4 中使用的 LMD 特征包括：

| 字段 | 含义 |
| --- | --- |
| `lmd_totalirrad` | 局地总辐照相关量。 |
| `lmd_diffuseirrad` | 局地散射辐照相关量。 |
| `lmd_temperature` | 局地气温。 |
| `lmd_pressure` | 局地气压。 |
| `lmd_windspeed` | 局地风速。 |
| `lmd_winddirection` | 局地风向，代码中转换为 `lmd_wind_x`、`lmd_wind_y`。 |

在工程语境里，LMD 可以理解为“更贴近电站现场的气象观测或局地修正信息”。如果 NWP 给出大尺度趋势，LMD 就提供现场附近的修正依据。

### 3.3 mixed

`mixed` 表示 NWP 与 LMD 的混合输入。问题 4 中，脚本会比较三种输入模式：

| 输入模式 | 使用特征 | 作用 |
| --- | --- | --- |
| `nwp` | 只使用 NWP 特征。 | 检查粗尺度天气预报本身的预测价值。 |
| `lmd` | 只使用 LMD 特征。 | 检查局地气象信息的修正能力。 |
| `mixed` | 同时使用 NWP 和 LMD 特征。 | 评估多源气象融合是否能进一步降低误差。 |

当前最优结果来自 `FusionModel_mixed`，说明 NWP 的未来天气趋势和 LMD 的局地修正信息具有互补性。

## 4. 评价指标

项目中有两类指标：一类是常规误差指标，便于直观理解预测偏差；另一类是附件口径指标，便于课程评分和工程考核。

### 4.1 常规误差指标

| 指标 | 中文含义 | 趋势 | 如何理解 |
| --- | --- | --- | --- |
| `RMSE` | 均方根误差。 | 越小越好。 | 对大误差更敏感，适合观察预测曲线是否出现明显偏离。 |
| `MAE` | 平均绝对误差。 | 越小越好。 | 表示平均每个白昼点偏差多少 MW，更直观稳定。 |
| `MAPE` | 平均绝对百分比误差。 | 越小越好。 | 用百分比表达相对误差；低功率点附近可能更敏感。 |

在问题 4 的局地校正结果中，`FusionModel_mixed` 的白昼 `RMSE=0.3069 MW`，`MAE=0.2135 MW`，`MAPE=18.10%`，说明混合输入下的平均偏差已经明显低于单独 NWP 输入。

### 4.2 附件口径指标

附件口径指标先把功率误差除以装机容量，得到归一化误差，再在白昼样本上统计。项目共享函数 `daylight_metrics` 统一计算这些指标，避免不同链路口径不一致。

| 指标 | 中文含义 | 趋势 | 项目中的计算含义 |
| --- | --- | --- | --- |
| `E_rmse` | 归一化均方根误差。 | 越小越好。 | 将 RMSE 按装机容量归一化，是最核心的误差指标。 |
| `E_mae` | 归一化平均绝对误差。 | 越小越好。 | 将 MAE 按装机容量归一化，反映平均偏差水平。 |
| `E_me` | 归一化平均误差。 | 越接近 0 越好。 | 保留正负号，用于判断系统性高估或低估。 |
| `r` | 相关系数。 | 越接近 1 越好。 | 判断预测曲线与真实曲线的形状一致性。 |
| `C_R` | 准确率。 | 越高越好。 | 当前代码按 `(1 - E_rmse) * 100%` 计算。 |
| `Q_R` | 合格率。 | 越高越好。 | 当前代码统计归一化绝对误差小于 0.25 的白昼样本占比。 |

指标读取时可以遵循一个简单规则：先看 `E_rmse` 是否下降，再看 `C_R` 和 `Q_R` 是否提高，最后用 `r` 判断曲线形状是否跟真实出力一致。如果 `E_me` 明显偏正或偏负，说明模型可能存在系统性低估或高估，需要回到特征或样本划分中排查。

## 5. 当前项目结果怎么读

当前结果可以概括为三条逐步增强的工程链路。

| 链路 | 最优模型或输入 | 关键结果 | 结论 |
| --- | --- | --- | --- |
| 历史功率基线 | `FusionModel` | `E_rmse=0.0833`，`C_R=91.67%`，`Q_R=98.07%`。 | 没有未来天气时，历史功率仍能提供可用保底预测。 |
| 气象预报融合 | `FusionModel` | `E_rmse=0.0699`，`C_R=93.01%`，`Q_R=99.76%`。 | 加入目标日 NWP 后，模型能提前感知天气变化，误差下降。 |
| 局地校正融合 | `FusionModel_mixed` | `E_rmse=0.0465`，`C_R=95.35%`，`Q_R=99.84%`。 | NWP 与 LMD 混合输入表现最好，说明多源气象对光伏日前预测有实际收益。 |

这三个结果适合在视频或答辩中连起来讲：项目不是简单比较模型分数，而是在模拟实际电站预测系统逐步接入更多可用信息。历史功率是兜底，NWP 提供目标日天气趋势，LMD 提供局地修正，mixed 输入把两类气象信息结合起来。

## 7. 答辩和录屏推荐说法

建议这样解释项目主线：

> 本项目面向光伏电站日前发电计划场景，输入包括历史功率、数值天气预报 NWP 和局地气象 LMD。模型侧比较 PureLSTM、FusionModel 和 BiFusionModel，最终以 FusionModel 作为主要展示链路。结果表明，输入信息从历史功率扩展到 NWP，再扩展到 NWP+LMD 的 mixed 模式后，白昼归一化误差持续下降，说明多源气象融合对日前预测有稳定收益。

不建议说“爬取网站数据”或“AI 总结出来的结果”。本项目实际做法是读取本地站点功率、NWP 和 LMD 数据，运行 PyTorch 训练脚本，生成预测表、指标 CSV、诊断图和运行摘要，再由 Streamlit 工作台和 GitHub Pages 做展示。
