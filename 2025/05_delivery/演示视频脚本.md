# 3 分钟演示视频脚本

目标：录制一个 MP4 文件，分辨率不低于 720P，总时长控制在 3 分钟以内。视频重点展示项目工程价值、一键运行、预测工作台、核心指标和交付完整性。

## 录制前准备

1. 打开 PowerShell，进入项目根目录。
2. 确认依赖已安装：`pip install -r 2025\requirements.txt`。
3. 先运行一次轻量验证：`python 2025\run_project.py --show all`。
4. 桌面保留 `2025\start_software.vbs` 或打开 `software_launcher.py` 启动器。
5. 浏览器提前关闭无关标签，缩放建议 100%。
6. 不在视频中展示任何 API 密钥、本机 token 或私人配置。

## 录屏路线

推荐顺序：Pages 首屏、项目目录、双击启动器、工作台首页、运行结果页、训练控制页、运行解读页、最终提交包清单。

## 视频质量检查

- 文件格式：MP4。
- 分辨率：720P 以上，推荐 1920x1080。
- 时长：2 分 40 秒到 3 分钟之间。
- 声音：无明显噪声，语速稳定。
- 画面：不出现密钥、私人目录以外的隐私窗口。
- 内容：必须出现一键启动、核心功能、关键指标和工程意义。
