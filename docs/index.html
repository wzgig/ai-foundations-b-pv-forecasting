工程流程

项目不是静态图表堆叠，而是从数据、模型、指标到展示入口的一条可复现链路。

业务目标与评价口径明确日前预测任务、装机容量归一化指标和运行约束。
站点机理诊断整理站点功率、NWP、LMD，并进行理论功率与偏差诊断。
深度预测模型比较 PureLSTM、FusionModel、BiFusionModel 和 checkpoint 复用。
运行场景归因分析天气场景、输入特征和空间降尺度对误差的影响。
工作台运行用 Streamlit 展示指标、图表、代码索引和受控训练入口。

模型与指标口径

公开页保留最核心的术语解释，完整说明见仓库中的名词解释文档。

PureLSTM纯 LSTM 时间序列基线，用于判断只依赖序列记忆时的保底预测能力。
FusionModelLSTM、TCN、MLP 多分支融合模型，是当前三条预测链路中最稳定的展示主线。
BiFusionModel结合 BiLSTM、TCN 和 Transformer 的增强结构，用于检验更复杂模型是否带来稳定收益。
NWPNumerical Weather Prediction，目标日前可获得的数值天气预报，提供辐照、温度、湿度、风速等未来天气信息。
LMD / mixedLMD 表示局地气象数据；mixed 表示 NWP+LMD 混合输入，当前最优结果来自 FusionModel_mixed。
E_rmse / C_R / Q_R白昼评价指标。E_rmse 越小越好，C_R 和 Q_R 越高越好，当前 mixed 链路达到 C_R 95.35%。
