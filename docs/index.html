工程流程

项目不是静态报告堆叠，而是从数据、模型、指标到展示入口的一条可复现链路。

题面与附件明确日前预测任务、装机容量归一化指标和交付约束。
数据与物理分析整理站点功率、NWP、LMD，并进行理论功率诊断。
深度预测模型比较 PureLSTM、FusionModel、BiFusionModel 和 checkpoint 复用。
场景与消融分析天气场景、输入特征和空间降尺度对误差的影响。
工作台交付用 Streamlit 展示指标、图表、代码索引和受控运行入口。

本地运行

GitHub Pages 只发布静态项目页，不能运行 Streamlit。完整软件界面需要在本地克隆仓库后启动。

python -m streamlit run 2025\app.py

python 2025\run_project.py --show all
